How does this work?

Home Assistant sends every state change of every entity to every open dashboard. A weak wall panel spends nearly all its CPU on updates it never displays. This add-on sits between the panel and Home Assistant, recognises the panel by its user and forwards only the entities it needs. Login, the dashboard itself and all other traffic pass through unchanged. If anything goes wrong, connections fall back to the unfiltered stream, so the panel keeps working.
